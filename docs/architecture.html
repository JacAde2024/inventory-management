Factory Inventory Management System

Full-stack demo application — architecture, tech stack, and data flow overview.

Vue 3 + Vite FastAPI (Python) In-memory JSON data

Tech Stack

Frontend
Vue 3 · Vite
  • Composition API
  • vue-router 4 (client-side routing)
  • axios (HTTP client)
  • Port 3000
Backend
FastAPI
  • Python ≥3.11, Pydantic models
  • uvicorn ASGI server
  • CORS enabled (allow all origins)
  • Port 8001 · /docs for OpenAPI UI
Data Layer
Static JSON files
  • No database — loaded into memory at startup
  • server/data/*.json
  • Loaded once via mock_data.py
  • Filtering happens in Python, in-request
Tooling
uv · npm
  • uv venv && uv sync (backend)
  • npm install (frontend)
  • pytest + httpx for backend tests
  • scripts/start.sh one-command launch

Request / Data Flow

1
User interacts with a filter or navigates to a view
e.g. selects a warehouse in FilterBar.vue, which writes to the shared useFilters.js refs.
2
View reads current filters and calls the API client
getCurrentFilters() builds a filter object; the view calls a method on api.js (axios).
3
axios sends an HTTP GET to FastAPI
Query params (warehouse, category, status, month) are appended to the request URL.
4
FastAPI applies filters in-memory
apply_filters() / filter_by_month() run over Python lists already loaded from JSON — no DB query, no disk I/O per request.
5
Pydantic validates and serializes the response
Response models (e.g. InventoryItem, Order) enforce shape before JSON is returned.
6
Vue stores the result in a ref and derives computed data
Raw API data lands in refs (e.g. allOrders); templates render from computed() properties built on top.
